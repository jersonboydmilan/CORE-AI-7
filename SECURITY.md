# Security Policy

## Scope

This repository (`core-ai-7`) contains research documentation, architecture
specifications, and sanitized evidence — no executable source code. There
is no code-level attack surface in this repository itself.

For the private implementation's security scope and hardening notes, see
the private repository's security policy (not public).

## Reporting a vulnerability

If you believe you have found a security issue in the CORE-AI/7 private
implementation, or a disclosure problem in this public repository (e.g.,
sensitive information that should not be public), please practice
responsible disclosure:

1. **Do not open a public issue for a security or disclosure
   vulnerability.**
2. Report privately via the contact form at
   <https://www.jersonboydmilan.com>, or through GitHub's private
   *Security → Report a vulnerability* advisory flow on this repository.
3. Include: affected document or claim, why it is a concern, and (if
   applicable) what you believe should not be public.

You can expect acknowledgment within 7 days and a status update within 30.
