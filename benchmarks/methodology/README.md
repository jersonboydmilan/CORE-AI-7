# Methodology

Scenario-level methodology detail supporting the entries in
[../README.md](../README.md). Each scenario follows the validation chain
defined in
[../../docs/validation/VALIDATION-METHODOLOGY.md](../../docs/validation/VALIDATION-METHODOLOGY.md).

This directory intentionally does not contain executable benchmark
harnesses — those are part of the private implementation. It contains only
the public-safe scenario, build, workload, and acceptance-criteria
definitions referenced by [../README.md](../README.md).
